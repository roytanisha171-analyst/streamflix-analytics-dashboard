# 🎬 StreamFlix Analytics Dashboard

## 📌 Project Overview

This project simulates a streaming platform analytics system using **MySQL** and **Power BI**.

The objective was to design a relational database, analyze business data using SQL, and create an interactive dashboard for business insights.

---

## 🛠️ Tools Used

- MySQL
- SQL
- Power BI

---

## 📊 Dashboard Features

- Total Users
- Total Revenue
- Total Shows
- Total Views
- Revenue by Subscription Plan
- Users by Subscription Plan
- Top 10 Most Watched Shows
- Shows by Genre
